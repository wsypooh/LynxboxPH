Steps are keyed to the recording's marks; see `out/meter-readings.json` for when each happens. Keep lines short so they finish before the next step.

| Step | On screen | Narration |
| --- | --- | --- |
| start | Invoices list | "Open the Invoices page." |

| bulk | Bulk Actions menu | "Open Bulk Actions." |
| readings | Enter Meter Readings | "Choose Enter Meter Readings." |
| enter | Type the readings | "Type each tenant's present reading. The consumption and amount are worked out for you." |
