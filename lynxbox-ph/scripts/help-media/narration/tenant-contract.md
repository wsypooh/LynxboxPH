# Narration: Attach a lease contract

Steps are keyed to the recording's marks; see `out/tenant-contract.json` for when each happens. The demo closes the dialogs without uploading.

| Step | On screen | Narration |
| --- | --- | --- |
| start | Tenants list | "Lease contracts are attached to the contract itself. Start on the Tenants page." |
| edit | Click the pencil icon | "Click the pencil icon to edit the tenant." |
| contracts | Contracts section | "Scroll to Contracts. Each contract has an Attach lease PDF button." |
| attach | Click Attach lease PDF | "Click Attach lease PDF." |
| details | Upload dialog, Lease Contract category | "The category is already set to Lease Contract. Add a note if you like, and choose the file." |
| cancel | Cancel (demo only) | "Click Upload. The lease now shows under this contract's period in the tenant's Documents list." |
